# THD AI – community discussions

The shared conversation space for student-led open source at TH Deggendorf. Open to every cohort and discipline. The repository URL keeps its original `WS23` name so existing discussion links continue to work.

![THD AI campus banner](https://raw.githubusercontent.com/THD-AI/.github/main/assets/thd-ai-banner.png)

| Conversation | Where to post |
| --- | --- |
| Meet people and introduce yourself | [General](https://github.com/orgs/THD-AI/discussions/categories/general) |
| Ask for help | [Q&A](https://github.com/orgs/THD-AI/discussions/categories/q-a) |
| Bring a project or find collaborators | [Ideas](https://github.com/orgs/THD-AI/discussions/categories/ideas) |
| Show what you built | [Show and tell](https://github.com/orgs/THD-AI/discussions/categories/show-and-tell) |
| Community news | [Announcements](https://github.com/orgs/THD-AI/discussions/categories/announcements) |

Members can create repositories and run their own projects. Public contributions through forks and pull requests are welcome without joining. See [how to contribute](https://github.com/THD-AI/.github/blob/main/CONTRIBUTING.md) and the [project directory](https://github.com/THD-AI/.github/blob/main/PROJECTS.md).
